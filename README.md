# BF1RoguexKade

Star Wars Battlefront (2004) — Mr Rogue's **BF1GameExt** (split screen, extended limits, EGM's patches, ragdolls, console spawn screens)
with Ben James's add-on loader and generic MODS page (v6.4), so Ben's mods (`dinput8_bf1sprint` / `bf1combo` / `bf1cloth` /
`bf1cpchange`) ride along as `GameData\dinput8_*.dll` and put their options on OPTIONS > MODS.

- `README.txt` — Mr Rogue's original notes (v6.3). `README_v6.4.txt` — what v6.4 adds.
- Build: Visual Studio 2022, Release | Win32 → `bin\Release\dinput8.dll`. Pushes build automatically (`.github/workflows/build.yml`), artifact `dinput8`.
- Credits: Mr Rogue (BF1GameExt), Kade Fett, Antstafer & abkarino (EGM, CC BY-NC 4.0), Dark_Phantom, S1thK3nny / Ryan Hank / Sleepy (BF2GameExt), Bullet Physics (zlib). Not for sale.
